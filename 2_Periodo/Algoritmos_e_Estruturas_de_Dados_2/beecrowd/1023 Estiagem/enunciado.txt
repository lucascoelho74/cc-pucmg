1023 - Estiagem
https://judge.beecrowd.com/pt/problems/view/1023
------------------------------------------------------------------------
Uma cidade em racionamento. Para cada imóvel você recebe o número de
moradores e o consumo total de água. O consumo per capita daquele imóvel
é o consumo total dividido pelos moradores, arredondando para baixo.
Agrupe por consumo per capita e informe, em ordem crescente de consumo,
quantas pessoas (não quantos imóveis) consomem cada valor. No fim, o
consumo médio por habitante da cidade: consumo total dividido pelo total
de moradores.

ENTRADA
  Vários casos. Cada caso começa com N (1 ≤ N ≤ 10⁶), o número de imóveis,
  seguido de N linhas com dois inteiros: moradores X (1 ≤ X ≤ 10) e
  consumo Y (1 ≤ Y ≤ 200). A entrada termina com zero.

SAIDA
  Para cada caso, Cidade# n:, depois uma linha com os grupos no formato
  pessoas-consumo separados por espaço, e Consumo medio: X m3. com duas
  casas decimais. Linha em branco entre os casos, mas não depois do
  último.

EXEMPLO DE ENTRADA
    3
    3 22
    2 11
    3 39
    2
    1 1
    3 2
    0

EXEMPLO DE SAIDA
    Cidade# 1:
    2-5 3-7 3-13
    Consumo medio: 9.00 m3.

    Cidade# 2:
    3-0 1-1
    Consumo medio: 0.75 m3.

PEGADINHA
  São duas armadilhas de arredondamento: o consumo per capita trunca, e as
  duas casas do consumo médio também são truncadas, não arredondadas.
