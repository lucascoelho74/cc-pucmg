Para usar o css precisa usar "link" e enter:
<link rel="stylesheet" href="">

||------------------------------------------------------------------------------||

Para criar um paragrafo, pressionar p e enter:
<p></p> 

Obs -> com classes usando o objeto no css:
<p class="palavra1" >Hello World!</p>
<p class="palavra2" >World 2</p>
.palavra1{
  color: blue;
}
.palavra2{
  color:brown;
}
// colocar o ".palavra1" e "palavra2" no css

||------------------------------------------------------------------------------||

Para usar div, digitar div e enter:
<div></div>

Obs -> com classes usando o objeto no css:

    <a class="sidebar-texto" href="">Sobre mim</a>
