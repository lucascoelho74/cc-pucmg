## Currículo (semana 3)

Página de currículo feita em HTML e CSS, na pasta `html-semana3/public`:

- `index.html` — estrutura da página
- `style.css` — fontes, cores e espaçamentos
- `perfil.jpg` — foto usada no cabeçalho

O layout usa CSS Grid em três áreas (cabeçalho, coluna da esquerda e coluna da
direita) e tem um breakpoint em 780px que empilha tudo numa coluna só no celular.
O menu de navegação tem o Home, o Projetos apontando para a página futura
`projetos.html` e o Contato levando para o meu LinkedIn.
